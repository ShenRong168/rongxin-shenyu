# IG「溫馨情境」第 N 輪 Reels 設計

## 目標

在 Instagram 親子／生活帳號恢復三支連續的 Reels 佇列。每支皆為 1080×1350 的家庭插畫、15 秒置中 Ken Burns 推鏡、Pillow 產生的字幕 PNG 疊圖，以及按讚型 CTA；不導流陪伴服務、不採輪播或靜態貼文。

## 內容與順序

1. **溫和教養解惑**：家長平靜接住幼兒動手的瞬間。字幕說明孩子不是變壞，而是尚未能用言語表達。
2. **被捧在手心**：成人手掌輕托幼兒臉頰，只呈現臉與手，床單或被子作為簡化背景。
3. **出門前的外套**：成人替孩子穿上外套、準備出門；以身體靠近與衣料動作表達日常照顧。

第三支避開既有的螢幕與傾聽、共讀、哭後安慰、手足和好、全家午後、分享玩具、收拾稱讚與繪本情境。

## 產線與資料流

每一支在同一交付單位內完成：產生一張新的插畫 PNG → 以 `scripts/render_ig_reel.py` 產出 MP4 → 檢查影片規格與抽格畫面 → 加入單一 Instagram `queued` 排程 → commit、push、以公開網址驗證 PNG 與 MP4。字幕由 renderer 的 Pillow + ffmpeg overlay 路徑處理，不使用 SRT、`drawtext`、`subtitles` 或 `ass`。

日期依既有節奏為 2026-09-14、09-16、09-18 的 12:30（+08:00）。排程內容只使用親子生活內容與三個相關 hashtag，並以正向按讚邀請作結；不使用留言、收藏、反問或自我檢討式 CTA。

## 驗收與錯誤處理

- 每張圖：1080×1350、畫面無文字；人物表情溫和、無驚恐或責備。
- 每支 MP4：可解碼、1080×1350、30 fps、15 秒；字幕面板保持在底部安全區且不遮住主要臉部。
- 寫排程前先以 `npm run schedule:pull` 同步遠端真相；若同步失敗，停止新增排程並回報。
- 推送後以 `curl -I` 驗證公開圖片與影片網址均為 HTTP 200；若 Pages 尚未部署，等待並重試，未成功不可將該支列為完成。
- 每支完成即回填派工與 vault 執行紀錄；三支全部完成後才勾選主任務、更新 README 與索引。

## 範圍

不更動既有 `school-eve-ready` 暫停排程、不改 Reel renderer、不處理優先序之後的 FB 配圖或圖生影片研究。
