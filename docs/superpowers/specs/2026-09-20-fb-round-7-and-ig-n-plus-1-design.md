## Visual Design

FB 卡沿用 `#A9BA9D` 底色、`#173E35` 主文字、`#C9A86A` 框線與 `#F6F0E5` 品牌面板；左下逐字保留「榮心紳語 InnerDialogueStudio」。文案及排程 ID 必須逐字採用派工。

IG「搶玩具」以平靜蹲下的家長、兩位孩子與玩具為核心，臉與手位於上方三分之二，底部留 360 px 字幕區；動作表達學習溝通，不描繪責備或驚恐。中秋以全家四人在陽台／窗邊剝柚子並看月亮為核心，暖色水彩、無文案與月餅廣告感。

兩支 IG 均用既有爸爸、媽媽、弟弟、妹妹角色圖作參考。搶玩具取一位家長與兩位孩子參考；中秋取四位角色參考。若媽媽角色有明顯頭身比例或年齡漂移，重生成。

## Delivery Flow

每個素材獨立完成：生成／渲染 → 視覺檢查 → 尺寸與媒體驗證 → 新增單平台 queued 排程 → 只提交本次檔案 → 推送 → `curl -L` 驗證公開 URL 200。每一項都在 vault 的回報區記錄檔案、尺寸、色票／角色參考、工具與 curl 輸出，並建立當日執行紀錄；兩項母任務全數完成後才勾選。

## Guardrails

- FB 僅建 Facebook，不能建立 Threads。
- IG 僅建 Instagram，文案使用按讚 CTA，不加留言／收藏 CTA 或反問句。
- 不修改既有 `render_ig_reel.py`，字幕維持 Pillow PNG overlay。
- 不混入工作區既有的未關聯變更。
- 若第一張 FB 無法在 9/21 前公開驗證，改排 9/23 並在回報區註明；中秋最遲 9/24 完成。
